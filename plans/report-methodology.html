指数日报方法论 · 改进方案

2026年5月26日 · 版本 1.0 · 待审查

目标：将当前面向短线交易的日报，改造为面向中长线持仓（数周至数月）的日报。核心原则：周线定方向，日线找买点，「观望等待」是合法常态。

一、诊断：当前报告的三个系统性问题

问题 1：只有日线视角，没有周线框架

所有技术指标取自 TradingView 日线 /technicals/。日线 RSI 67 + 均线全多头 → 结论「强烈看多」。但如果周线已经连涨 8 周、RSI 85，日线看多恰恰是周线追顶。

案例：纳指日线均线多头排列 → 5/26 报告写「强烈看多」。但如果在周线级别，纳指可能处于连续上涨后的加速赶顶阶段。缺少周线框架，日线信号极易产生追涨杀跌。

问题 2：交易区间是日内级别，不是中长线级别

以 5/26 沪深300 建议为例：

参数当前报告问题中长线合理值
入场区间4,880−4,920宽度仅 0.8%4,700−4,780（3%，周线支撑）
止损4,820仅 −1.5%，一个日线波动4,450（−5.5%，周线 EMA50 下方）
目标5,000仅 +1.9%，日内即可到达5,200→5,400（+10−14%，前期周线高）
仓位15%（随意）未基于风险计算基于止损距离 × 总风险 2% 反推

0.8% 入场区间 + 1.5% 止损 → 一次正常的日线回调就会被「洗出去」。

问题 3：没有历史锚定，每天都是新故事

缺少 52 周位置判断、缺少周线趋势阶段识别、缺少前期高/低点参照。没有这些锚，每天只能对当日价格做反应，自然追涨杀跌。

二、解决框架：三层时间体系

层级时间框架职能权重
战略层周线判断趋势方向。具有否决权——周线空头下，日线再好看也不做多。最高
战术层日线在周线方向内，判断当前价格距离周线支撑/阻力有多远。找入场区间。辅助
确认层4H只在周线+日线都允许时参考。cron 自动场景可省略。可选
黄金规则：周线多头 → 只在日线回调到周线支撑位时考虑做多。周线空头 → 不做多，等周线转势。永远不因为「怕错过」而追高。

三、新指标体系

新增指标时间框架用途
52 周位置—判断处于高位/中位/低位。距 52 周高 <3% → 谨慎。
周线 MACD周线趋势方向与动能。柱状线方向比交叉更重要。
周线 EMA 排列周线EMA10/20/50 的多空排列。全多头=趋势健康，交叉=转势警告。
周线 ATR(14)周线止损和仓位计算基准。止损 = 关键支撑 − ATR×1.5。
前期周线高/低点周线真正的支撑阻力。日线 Pivot 只作参考。
ADX(14)日线>25 有趋势，<20 震荡。震荡市不交易。

四、区间标准：短线 → 中长线

参数短线标准（旧）中长线标准（新）
入场区间宽度0.5−1.5%3−5%（周线支撑区域）
止损距离1−2%5−10%（周线关键支撑下方 + 1.5×ATR）
第一目标1−3%5−15%（前期周线高点）
第二目标无8−20%（下一周线阻力区）
盈亏比要求无≥ 1.5:1
仓位计算随意指定基于止损距离，单笔风险 ≤ 总资金 2%

五、报告结构：旧 vs 新

❌ 旧结构（短线导向）

  1. 行情一览（日涨跌表）
  2. 关键价位（日线 Pivot）
  3. 重大新闻
  4. 技术面速览（日线指标堆砌）
  5. 次日交易计划
  6. 风险矩阵

每天都有建仓建议。隐含假设：每天都应该交易。

✅ 新结构（中长线导向）

  1. 周线结构图（趋势阶段 + 关键价位）
  2. 宏观快照（VIX/美元/跨市场资金流）
  3. 重大事件（原因→影响→情景）
  4. 日线健康检查（在周线框架内看）
  5. 持仓评估 & 观察清单
  6. 风险矩阵 + 下周催化剂

「观望等待」是合法答案。不交易的日子远比交易多。

六、新报告格式示例（沪深300）

📊 沪深300 — 周线多头 ✅ · 日线逼近阻力 ⚠️

周线结构
趋势：多头（EMA10>EMA20>EMA50，连续 8 周收于 EMA10 上方）
阶段：趋势中段偏后（距 52 周低点 +28%，距 52 周高点 −6%）
支撑：4,700−4,750（周线 EMA20 + 前期突破平台）
阻力：5,200（2025 年 10 月高点）

日线健康检查
RSI(14)：61 — 中性，未超买但也不在低位
ADX(14)：32 — 趋势健康
距周线支撑：+4.2%（尚未回调到理想入场区）
距周线阻力：+5.1%

📋 建议：观望等待 ⏸️
→ 当前不追：盈亏比不足（距目标仅 5%，距止损 5.5%，≈1:1）
→ 等回调入场：理想入场区 4,700−4,780（周线 EMA20 附近，−4%）
→ 若直接突破 4,955：等回踩确认，不追高
→ 计划仓位 20−25%，止损 4,450，目标 5,200→5,400，盈亏比 >2:1

历史参照：上次从类似位置（2025/11，距前高 6%）回调了 7% 才继续上涨。当前距周线 EMA20 4.2%，历史均值回调深度的 3−5%。

七、硬规则（写入 cron prompt）

  1. 周线决定方向——周线空头下不推荐做多，无论日线多好看。
  2. 入场区间宽度 ≥ 3%——日线级别的窄幅区间不是中长线入场点。
  3. 止损低于周线关键支撑，距离 ≥ 5%——日线 Pivot S1 不是中长线止损位。
  4. 「观望等待」是合法建议——每天报告不等于每天交易。
  5. 入场前三个必答题：
    • 当前处于周线趋势的什么阶段？（初期/中期/末期）
    • 为什么不等到更低的位置？（如果答案是「怕错过」→ 禁止）
    • 止损在周线结构的哪个位置？（必须有明确周线理由）
  6. 日线 RSI >70 或 <30 → 只建议等待——极端位入场盈亏比差。
  7. ADX(14) <20 → 震荡市——不推荐方向性建仓。
