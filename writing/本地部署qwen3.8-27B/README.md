## 使用资料

文档保留 Markdown 格式，图片使用相对路径。下载仓库后，保留本目录结构即可阅读和运行脚本；测试前，按运行说明修改 `benchmark_config.json` 中的模型路径。

本目录包含原始资料和测试结果，未包含模型权重。Python 字节码与 Matplotlib 字体缓存未上传。历史记录中的本机路径及备份引用按原样保留。
