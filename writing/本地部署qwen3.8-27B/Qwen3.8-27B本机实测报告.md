# Qwen3.8-27B 本机实测报告

测试日期：2026-09-05。修订日期：2026-09-06。

本报告包括**共同性能、Thinking＋xhigh 质量、上下文容量**三部分。性能和容量采用 18:55 开始的完整测试记录，质量采用 23:03 开始的补测结果；此前生成条件不同的质量成绩已被替换。

## 7. 配置核验

本文引用的九个阶段均为 11 项自动核验通过、4 项 `unknown`，最终保留 `unverified`。加载文件、量化名、窗口、槽位、GPU 卸载、Batch/UBatch、K/V 类型和 Flash Attention 已通过核验。

未自动确认的项目为 Context Shift、Prompt Cache、视觉投影组件和推测解码。九份底层日志均写明 `no implementations specified for speculative decoding`，可补充说明未配置推测解码实现；自动解析器没有覆盖这一格式，本文不改写原始判定。

`completed, unverified` 表示请求已执行完、部分配置证据仍缺失。本文选用的 225 次请求均已核对输入计数、完整响应和评分，配置未知项继续随结果列出。

| 引擎处理速度 | 关闭 Thinking 的 8K 共同性能中，Q4_K_S 的 Prefill、Decode 中位数分别为 780.85、34.00 Token/s，均为三组最高 |
| 日常基础任务与等待 | Thinking＋xhigh 下三组各 63/63 成功；Q4_K_S 的总体 TTFA 中位数最短，为 8.41 秒 |
| 模型权重占用 | 16K 质量配置中，Q3_K_XL 的 GPU 模型缓冲为 11.398 GiB，是三组中最小的 |
| 长输入的容量与等待 | Q3_K_XL 关闭 Thinking，在 128K 窗口下完成约 116K 输入的检索；TTFT 中位数 348.96 秒，总耗时 353.84 秒 |

新的质量测试确认三种量化都满足了这组基础任务与接口格式要求。性能与容量记录则补上了另外两个问题：引擎处理输入和生成输出有多快，以及输入变长后缓存占用、首个输出等待和生成速度怎样变化。

用于本次分享时，应把三部分一起看：选择能完成任务的配置，再结合模型占用、输入长度和业务能接受的等待时间取舍。以上比较均限于对应批次的本机预设；权重和 Batch/UBatch 的单独影响尚未测量。

可选的控制变量对比、接近最大窗口的边界输入和 RAG 对照均未执行，方法保留在[测试方案](Qwen3.8-27B上下文与性能测试方案.md)中。
