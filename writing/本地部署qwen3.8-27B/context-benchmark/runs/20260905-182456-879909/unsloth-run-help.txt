                                                                                                                                                                                                                                                
 Usage: unsloth run [OPTIONS]                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                
 Alias for `unsloth studio run`.                                                                                                                                                                                                                
                                                                                                                                                                                                                                                
┌─ Options ────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --help  -h        Show this message and exit.                                                                                                                                                                                                │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Model ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --model,--hf-repo                  -hf                          <str>                                                      Model path or HF repo. Accepts llama.cpp-style `org/repo:variant` syntax. `-hf` / `--hf-repo` match               │
│                                                                                                                            llama-server's spelling.                                                                                          │
│ --gguf-variant                                                  <str>                                                      GGUF quant variant (e.g. UD-Q4_K_XL)                                                                              │
│ --max-seq-length,--context-length                               <int>                                                      Runtime context length in tokens (0 = model default for GGUF; 2048 for hub models) [default: 0]                   │
│ --gpu-memory-mode                                               <auto|manual>                                              GPU memory strategy for GGUF models. Auto lets Unsloth select GPUs and cap context to fit VRAM. Manual with       │
│                                                                                                                            default layers and context delegates placement and sizing to llama.cpp --fit.                                     │
│                                                                                                                            [default: auto]                                                                                                   │
│ --speculative-type                                              <auto|mtp|dspark|dflash|ngram|mtp+ngram|off|ngram-simple>  Speculative decoding mode for GGUF models. DSpark automatically uses a matching dspark-*.gguf sidecar when        │
│                                                                                                                            available. Default: unset (Unsloth auto).                                                                         │
│ --spec-draft-n-max                                              <int range> [1<=x<=16]                                     Maximum draft tokens per step for MTP or DSpark (1..16).                                                          │
│ --load-in-4bit                          --no-load-in-4bit                                                                  [default: load-in-4bit]                                                                                           │
│ --tensor-parallel                       --no-tensor-parallel                                                               Split a GGUF across GPUs by tensor (--split-mode tensor) instead of by layer. Multi-GPU only (no effect on one    │
│                                                                                                                            GPU); dense models gain decode speed, MoE usually don't.                                                          │
│                                                                                                                            [default: no-tensor-parallel]                                                                                     │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Advanced ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --verbose       -v             Log every API request, including the high-frequency polling that is deduplicated by default.                                                                                                                  │
│ --api-key-name          <str>  Label for the auto-generated API key [default: cli]                                                                                                                                                           │
│ --silent        -q                                                                                                                                                                                                                           │
│ --yes           -y             Accepted for backward compatibility; the tool policy no longer prompts.                                                                                                                                       │
│ --password              <str>  Set the INITIAL admin password non-interactively (headless setups), only when none is set yet. Also reads the UNSLOTH_STUDIO_PASSWORD env var, or `--password -` to read one line from stdin. A literal value │
│                                is visible in the process list and shell history. Rotate later with `unsloth studio reset-password`.                                                                                                          │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Server & network ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --port                   -p                      <int>                   [default: 8888]                                                                                                                                                     │
│ --host                   -H                      <str>                   [default: 127.0.0.1]                                                                                                                                                │
│ --frontend                                       <path>                                                                                                                                                                                      │
│ --api-only                                                               Serve only the API (no web UI), for a headless model server. Pairs with --secure to expose the API over the Cloudflare link alone.                                  │
│ --parallel,--n-parallel  -np                     <int range> [1<=x<=64]  llama-server parallel decode slots. N requests share one loaded model; each slot gets ctx/N KV cache. Default 4 (pre-PR hardcoded value). The Unsloth run settings  │
│                                                                          (Parallel Slots) can override it per load.                                                                                                                          │
│                                                                          [default: 4]                                                                                                                                                        │
│ --cloudflare                  --no-cloudflare                            Expose Unsloth on a PUBLIC internet URL via a free Cloudflare HTTPS tunnel, for non-api-only wildcard binds (0.0.0.0 or ::). Off by default; pass --cloudflare to   │
│                                                                          enable it (--secure implies it). --no-cloudflare forces it off but does not change a raw wildcard bind.                                                             │
│ --secure                      --no-secure                                Expose ONLY a Cloudflare HTTPS link: bind localhost and fail closed if the tunnel can't start. Without it, --no-secure also serves the raw 0.0.0.0 port, which is   │
│                                                                          reachable from anywhere on the network.                                                                                                                             │
│                                                                          [default: no-secure]                                                                                                                                                │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Tool calls ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --enable-tools                --disable-tools                  Force server-side tools (web search, code execution) on or off for every request. Default: on for every bind, with a request's own enable_tools: false (what the Unsloth UI   │
│                                                                sends) honored. /v1/messages takes the on direction per request (enable_tools) because it has no confirmation channel; the off direction still applies everywhere.            │
│ --disable-dns-pinning                                          Send the hostname (not the validated IP) in web fetches that go through an explicitly configured HTTP(S)_PROXY, so the proxy can apply hostname policy and TLS interception.  │
│                                                                Direct fetches stay pinned to the validated IP.                                                                                                                               │
│ --enable-tool-call-healing    --disable-tool-call-healing      Promote text-form tool calls (small GGUFs often emit <tool_call>...) back into structured calls on the client-tool passthrough. Default: on. An explicit                      │
│                                                                --disable-tool-call-healing is an absolute server kill-switch.                                                                                                                │
│ --enable-tool-call-nudging    --disable-tool-call-nudging      On the non-streaming client-tool passthrough, retry once with a short nudge when the model emitted a tool signal that healing could not repair. Default: on. No effect on     │
│                                                                streaming requests or the server-side agentic loop.                                                                                                                           │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Sampling ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --temperature               <float range> [0.0<=x<=2.0]  Pin the sampling temperature for every request that omits it, overriding the model's recommended value. Default: unset (use the per-model recommendation).                          │
│ --top-p                     <float range> [0.0<=x<=1.0]  Pin top-p (nucleus) sampling. Default: unset (per-model recommendation).                                                                                                            │
│ --top-k                     <int range> [-1<=x<=100]     Pin top-k sampling. Default: unset (per-model recommendation).                                                                                                                      │
│ --min-p                     <float range> [0.0<=x<=1.0]  Pin min-p sampling threshold. Default: unset (per-model recommendation).                                                                                                            │
│ --repetition-penalty        <float range> [1.0<=x<=2.0]  Pin the repetition penalty. Default: unset (per-model recommendation).                                                                                                              │
│ --presence-penalty          <float range> [0.0<=x<=2.0]  Pin the presence penalty. Default: unset (per-model recommendation).                                                                                                                │
└──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
